# FSM-Based 4-Floor Elevator Controller

This repository contains the RTL implementation of a **4-floor elevator controller** designed using **Verilog HDL** and a **Finite State Machine (FSM)**. The controller manages elevator movement between four floors based on user floor requests and was functionally verified using simulation.

## Features

* 4-floor elevator controller
* FSM-based control logic
* Floor selection using four input buttons
* Bidirectional movement (UP/DOWN)
* Functional verification using Icarus Verilog and GTKWave

---

## Repository Contents

### Source Files

* `elevator.v` – Elevator FSM and control logic
* `floor_counter.v` – Tracks the current floor of the elevator
* `timer.v` – Generates the timing required for elevator movement
* `top_module.v` – Integrates all modules into the complete design
* `testbench.v` – Testbench used for functional verification

### Simulation Files

* `top_module.vvp` – Compiled simulation file generated by Icarus Verilog
* `top_module.vcd` – Waveform dump file used for GTKWave visualization

## Verification

The elevator controller was verified through RTL simulation using Icarus Verilog and GTKWave. The simulation confirms correct floor transitions, state changes, and elevator movement according to the requested destination floors.

---

## Project Outcome

The design successfully demonstrates the implementation of a modular FSM-based elevator controller capable of handling floor requests, direction control, and floor tracking through RTL simulation.
